# 은수

한국어로 대화하는 로컬 AI 채팅 앱입니다. 일상 대화는 **Qwen3 4B 언어 모델**이 최근 대화를 참고해 새로 생성합니다. 낯선 단어를 이해할 필요가 있으면 모델이 스스로 표준국어대사전·우리말샘을 조회합니다. 별도의 한국어 모델을 처음부터 학습한 결과물은 아닙니다.

## 실행

현재 컴퓨터에는 Python 가상환경, 모델 실행기와 모델이 준비되어 있습니다.

```sh
./run.sh
```

http://localhost:8000 에서 엽니다. 기존 서버가 실행 중이면 Ctrl+C로 종료하세요. `python3 app.py`로 실행해도 프로젝트 `.venv`가 있으면 해당 환경으로 전환합니다. Ollama가 꺼져 있으면 프로젝트에 설치된 실행기를 자동으로 시작합니다. 모델 파일은 `~/.ollama`, 실행기와 토크나이저는 `.runtime/`에 저장됩니다.

## 다른 컴퓨터에서 처음 준비

Python 3.10+와 [Ollama](https://ollama.com/download)가 필요합니다. 기본 모델은 [Qwen3 4B Q4_K_M](https://ollama.com/library/qwen3:4b-instruct)이며 다운로드 약 2.5GB와 실행 메모리가 필요합니다. 현재 8GB Apple Silicon 환경을 기준으로 문맥 길이를 4096으로 제한했습니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/setup_tokenizer.py
# 별도 터미널에서 Ollama를 실행하거나 Ollama 앱을 여세요.
ollama serve
```

Ollama 실행 후 다음 명령으로 모델을 준비합니다.

```sh
ollama pull qwen3:4b-instruct
ollama create eunsu:qwen3-4b -f Modelfile
cp .env.example .env
./run.sh
```

`Modelfile`은 기본 모델의 가중치를 재사용하면서 한국어 채팅용 실행 설정과 비사고 모드 템플릿을 설정합니다. 추가 학습은 하지 않습니다. 현재 프로젝트에 설치된 CLI를 직접 쓰려면 `ollama` 대신 `.runtime/ollama/ollama`를 사용하세요.

## 대화 방식

사용자의 직접 발언을 별도 근거로 전달합니다. 모델이 이전 답변에서 추측한 내용은 사용자 사실로 옮기지 않습니다. 게임 이름이나 만든 물건처럼 이미 말한 내용을 다시 묻는 경우 이 근거에서만 답하도록 구성했습니다. 일상 어휘와 고유명사는 자동 사전 후보에서 제외해 일반 대화가 불필요한 뜻풀이로 바뀌지 않게 했으며, 명시적인 뜻 요청에는 여전히 사전을 사용할 수 있습니다.

기본 말투는 짧고 예의 있는 반말입니다. 존댓말을 원하면 대화에서 요청할 수 있습니다. 불필요한 재질문, 사용자 발언의 반복, 과한 위로를 줄이도록 하나의 시스템 지침으로 답변을 생성합니다. 문장을 형태소로 다시 조립하던 말투 후처리는 적용하지 않습니다. 소형 모델 특성상 말투가 항상 완벽히 지켜지는 것은 아닙니다.

- 최근 최대 16개 메시지와 한국어 시스템 지침을 로컬 모델에 전달합니다. 입력 길이 제한으로 긴 대화의 오래된 부분은 제외됩니다.
- 답변을 생성되는 대로 화면에 표시합니다. 실제 엔진 이름과 입력·출력 토큰 수는 응답 JSON에도 담깁니다.
- 모델에 연결하지 못하면 오류를 표시합니다. 정해진 문장을 실제 AI 응답처럼 대신 내보내지 않습니다.
- `답변 가르치기`로 저장한 답변은 우선 적용합니다. 이는 모델 가중치 학습이 아닌 질문·답변 저장입니다.
- 답변 전 같은 로컬 모델이 사전 확인이 필요한 단어를 최대 두 개 선택합니다. Kiwi의 기본형 후보 안에서 JSON 구조로 선택하고, 선택된 단어만 실제로 사전 조회합니다. 단어를 모르거나 뜻이 모호하면 사용자가 요청하지 않아도 조회할 수 있습니다. 평범한 인사에는 보통 조회하지 않습니다.
- 조회 결과를 모델에 전달해 원래 대화에 답하도록 합니다. 답변 아래에 모델이 확인한 검색어와 원문 출처가 표시됩니다. 검색 실패는 성공으로 표시하지 않습니다. 단어 선택과 답변에는 여전히 모델의 판단 오류가 있을 수 있습니다.
- 모델은 부정확한 내용을 말할 수 있고, 메모리와 문맥 범위가 제한되어 있습니다. 사전 규칙 대화보다 자유롭게 생성하지만 대형 클라우드 모델과 동일한 성능을 보장하지 않습니다.

`.env`에서 설정합니다. 파일은 Git에서 제외되고 서버 시작 시 읽힙니다. 기존 터미널 환경변수가 우선합니다.

```dotenv
CHAT_ENGINE="ollama"
OLLAMA_MODEL="eunsu:qwen3-4b"
OLLAMA_URL="http://127.0.0.1:11434"
STDICT_API_KEY=""
OPENDICT_API_KEY=""
```

`CHAT_ENGINE="rules"`로 지정하면 이전 규칙 대화로 명시적으로 전환할 수 있습니다. 일반 대화는 로컬 주소로만 전송되며, 다운로드 이후 모델 추론에는 인터넷이나 유료 AI 키가 필요하지 않습니다. 사전 요청 시 검색어만 국립국어원으로 보냅니다. 대화 기록은 브라우저에, 가르친 내용은 `data/eunsu.sqlite3`에 저장됩니다.

## 토크나이저 실험실

**한국어 형태소 모드**는 [Kiwi](https://github.com/bab2min/kiwipiepy)를 사용합니다. 공백 기준 분리가 아닙니다. 예를 들어 `먹었어요`를 `먹/VV + 었/EP + 어요/EF`로 분석합니다. 명사·동사·조사·어미와 원문 위치를 제공합니다. 원형 복원 때문에 표시 형태가 원문과 다르거나 두 형태소의 원문 범위가 겹칠 수 있습니다. 가짜 어휘 ID는 만들지 않습니다.

**실행 모델 BPE · 입력 본문 모드**는 [Qwen 공식 토크나이저](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507/blob/main/tokenizer.json)의 어휘·BPE 규칙으로 인코딩합니다. 실제 토큰 ID를 표시하고 그 ID 목록으로 원문을 복원할 수 있습니다. BPE는 단어보다 작은 바이트 조각도 사용하므로 한글 글자 하나가 여러 토큰으로 나뉠 수 있습니다. 단독으로 글자가 되지 않는 조각은 화면에 `⟨16진수 바이트⟩`로 표시하고, 모든 BPE 상자에 순번과 ID를 함께 표시합니다. 바이트를 공유하는 글자의 원문 범위가 겹치더라도 실제 ID마다 한 번만 집계합니다. 해당 모드의 수는 본문만의 토큰 수이며 시스템 지침·채팅 템플릿까지 포함한 실제 추론 입력 토큰 수와는 다릅니다. 실행 시 Ollama의 실제 모델 메타데이터에서 어휘와 ID 및 BPE 병합 규칙 전체를 읽어 로컬 토크나이저와 대조합니다. 불일치 모델에서는 실제 토큰이라고 표시하지 않고 오류를 냅니다.

전체 추론 입력을 본 뒤 본문 모드로 돌아오면 원래 입력한 문장을 복원합니다. `안녕하세요, 은수와 함께 한국어를 탐험해요!`는 현재 Qwen3 어휘에서 18토큰이며, Kiwi 분석 결과 13개는 별도의 형태소 개수입니다. 이 수치를 GPT의 토큰 수와 동일하게 보거나 한국어 토큰 감소의 근거로 사용하면 안 됩니다.

## 실제 대화의 전체 토큰 확인

답변 아래 **실제 추론 토큰 보기**를 누르세요. 실험실에서 다음을 선택할 수 있습니다.

- **실제 대화 · 전체 입력 토큰**: 모델에 실제로 보낸 시스템 지침·대화 이력·역할 구분 기호·사전 결과를 포함한 전체 입력과 BPE ID. 우리가 렌더링한 프롬프트를 Ollama에 그대로 전달하며, 백엔드 입력 토큰 수와 반환된 컨텍스트의 접두 ID까지 대조합니다.
- **1차 사전 판단 / 2차 답변 생성**: 각 단계의 입력과 기록을 따로 확인합니다. 입력 수 일치 여부와 실제 백엔드 입력·출력 토큰 수도 표시합니다.
- **출력 본문 · BPE 재인코딩**: 모델이 생성한 원문을 같은 어휘로 다시 인코딩한 ID입니다. 모델이 샘플링한 원본 ID 시퀀스라고 주장하지 않습니다. Ollama의 출력 통계에는 종료 신호 등이 포함되거나 다른 토큰 분할이 사용될 수 있어 목록 수와 다를 수 있습니다.

추론 기록은 서버 메모리에 최근 12건만 보관하고 브라우저에는 참조 ID만 저장합니다. 서버를 재시작하거나 오래된 기록이 만료되면 새 답변을 생성해야 합니다. 실험실의 JSON 내보내기로 선택한 단계의 토큰과 검증 정보를 저장할 수 있습니다.

## 사전 인증 키

[표준국어대사전](https://stdict.korean.go.kr/openapi/openApiInfo.do)에서 발급받은 키는 `STDICT_API_KEY`, [우리말샘](https://opendict.korean.go.kr/service/openApiInfo) 키는 `OPENDICT_API_KEY`에 넣으세요. 변경 후 서버를 재시작합니다. macOS 시스템 인증서를 활용하고 HTTPS 검증은 유지합니다. 별도 신뢰 CA가 필요하면 `SSL_CERT_FILE`을 설정할 수 있습니다.

## 검증

```sh
.venv/bin/python -m unittest discover -s tests
node --test tests/test_token_ui.cjs
node --check static/app.js
```

테스트는 한국어 형태소 분리, 실제 BPE ID 복원, 모델 이력 전달·스트림 처리·오류 처리, 자율 사전 선택·검색, 실행 모델 어휘/병합 검증, 추론 기록·만료 및 기존 학습 기능을 검증합니다. 실제 모델의 한국어 대화 품질은 별도 다중 턴 대화로 확인합니다.
